# Примитивная база данных (CLI)

Учебный проект «Примитивная база данных» — консольное приложение, реализующее хранение данных в JSON-файлах и поддерживающее базовые операции управления таблицами и данными (CRUD). Управление осуществляется командами, вводимыми в интерактивном режиме.

## Возможности

### Управление таблицами (DDL)
- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу (столбец `ID:int` добавляется автоматически)
- `list_tables` — вывести список таблиц
- `info <имя_таблицы>` — вывести схему таблицы и количество записей
- `drop_table <имя_таблицы>` — удалить таблицу (требует подтверждения)

### Операции с данными (CRUD)
- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — вставить запись (ID генерируется автоматически)
- `select from <имя_таблицы>` — вывести все записи таблицы
- `select from <имя_таблицы> where <столбец> = <значение>` — вывести записи по условию
- `update <имя_таблицы> set <столбец1> = <значение1>, ... where <столбец> = <значение>` — обновить записи по условию
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи по условию (требует подтверждения)

### Дополнительно по требованиям ТЗ
- Декораторы:
  - единая обработка ошибок (`handle_db_errors`)
  - подтверждение опасных операций (`confirm_action`)
  - замер времени выполнения (`log_time`)
- Кэширование через замыкание (используется для `select`):
  - повторный одинаковый `select` отрабатывает из кэша и печатает результат
  - кэш сбрасывается после операций, изменяющих данные (`create_table`, `drop_table`, `insert`, `update`, `delete`)
